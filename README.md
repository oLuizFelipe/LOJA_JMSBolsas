# 👜 JMS Bolsas

Projeto desenvolvido em grupo para a disciplina de **Desenvolvimento Web**.

O projeto consiste na criação de um site para uma loja de bolsas, utilizando **HTML e CSS**.

## 💻 Tecnologias

* HTML5
* CSS3

## 📌 Sobre o projeto

O site possui:

* Página inicial;
* Menu de navegação;
* Vitrine de bolsas e malas;
* Preços dos produtos;
* Seleção de cores de uma das malas;
* Seção sobre a loja;
* Informações de contato;
* Links para redes sociais;
* Layout responsivo para celulares.

```

## 🎯 Objetivo

Praticar os conhecimentos de **HTML, CSS e JavaScript** através da criação de uma página web para uma loja de bolsas.
